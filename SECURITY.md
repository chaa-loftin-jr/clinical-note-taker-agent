# Security Policy

## Supported Versions

This project is pre-release (`0.x`). Only the latest commit on `main` is
supported; there are no maintained release branches yet.

## Reporting a Vulnerability

If you find a security issue, please report it privately rather than opening
a public issue — open a GitHub issue asking for a private contact channel, or
reach out to the repository owner directly. Please do not include exploit
details or sensitive data in a public issue or pull request.
